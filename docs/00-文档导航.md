# 文档导航

## 项目简介

`myai-novel-webui` 是一个面向 AI 小说创作流程的前端控制台。它围绕书籍、章节、资源、阅读和个人运行配置组织页面，帮助使用者在同一个 WebUI 中完成从作品管理到章节成稿阅读的完整链路。

这个仓库当前的技术实现是 React + Vite + TypeScript 前端，开发模式下通过代理与本地后端服务通信。

## 这套文档适合谁

这批文档同时服务两类读者：

- 业务或使用者：希望快速理解系统能做什么、主要页面怎么配合。
- 开发或维护者：希望快速找到代码入口、理解架构边界、掌握路由权限与数据流约定。

## 使用这套文档时的约定

- 文档优先记录稳定事实，而不是逐行解释代码。
- 页面名称、路径、主要术语尽量与当前代码保持一致。
- 具体实现细节以源码为准，文档负责帮助读者更快建立整体理解。
- 当页面、路由、数据流发生明显调整时，应同步更新对应文档。
