# 页面与功能地图

这份文档按页面整理系统中的主要入口、页面职责、关键操作和页面之间的关系，方便业务使用者、测试同学和新开发者快速建立页面级认知。

## 1. 页面总览

| 页面 | 典型路由 | 主要职责 |
| --- | --- | --- |
| 登录页 | `/app/login` | 已有账号用户进入系统 |
| 注册页 | `/app/register` | 新用户创建账号并进入系统 |
| 书籍总览 | `/app` | 查看与创建书籍，选择一本书进入工作区 |
| 书籍工作台 | `/app/books/:bookId` | 管理单本书及其章节，跳转到章节、资源、阅读 |
| 章节工作台 | `/app/books/:bookId/chapters/:chapterNo` | 推进单章节 workflow，编辑阶段内容与任务 |
| 资源中心 | `/app/books/:bookId/resources` | 管理这本书的结构化资源 |
| 章节阅读 | `/app/books/:bookId/read` | 阅读 final 成稿 |
| 个人设置 | `/app/settings` | 配置用户级默认运行参数 |
| 404 页面 | `*` | 兜底未知路径 |

## 2. 登录页

- 路由：`/app/login`
- 页面目标：让已有账号用户恢复或建立会话。
- 主要操作：输入邮箱和密码，提交登录。
- 与其他页面的关系：
  - 登录成功后会返回目标页，或进入 `/app`。
  - 已登录用户不应继续停留在登录页。

## 3. 注册页

- 路由：`/app/register`
- 页面目标：让新用户创建账号。
- 主要操作：填写显示名称、邮箱和密码。
- 与其他页面的关系：
  - 注册成功后会进入应用主区域。
  - 与登录页一样，已登录用户不会停留在这里。

## 4. 书籍总览

- 路由：`/app`
- 页面目标：作为应用首页，展示当前用户可以进入的书籍列表。
- 主要操作：
  - 查看书籍卡片
  - 快速新建书籍
  - 点击书籍进入书籍工作台
- 关键展示信息：
  - 书籍标题
  - 简介
  - 目标章节数
  - 已批准章节数
  - 当前状态
- 与其他页面的关系：
  - 是整个业务流程的起点。
  - 进入某一本书后，侧边导航开始切换到书籍上下文。

## 5. 书籍工作台

- 路由：`/app/books/:bookId`
- 页面目标：作为一本书的总控页面，管理书籍信息和章节列表。
- 主要操作：
  - 修改书籍基本信息
  - 查看章节列表
  - 新建章节
  - 编辑已有章节
  - 删除书籍或章节
  - 为章节维护关联资源 ID
  - 跳转到章节工作台
  - 跳转到阅读页
- 关键展示信息：
  - 当前书籍信息
  - 已有章节及其状态
  - 每章的阶段完成情况（Plan / Draft / Review / Final）
  - 创建章节时可继承的默认 provider / model 参数
- 与其他页面的关系：
  - 它是书籍总览和章节工作台之间的桥梁。
  - 也是资源中心、阅读页的上游入口之一。

## 6. 章节工作台

- 路由：`/app/books/:bookId/chapters/:chapterNo`
- 页面目标：围绕单一章节推进创作工作流。
- 主要操作：
  - 查看章节当前 workflow 状态
  - 切换 Plan / Draft / Review / Final / Task 标签
  - 启动 plan、draft、review、repair、approve 等 workflow
  - 查看最近任务和任务历史
  - 查看与编辑阶段内容
  - 为本次 workflow 选择 provider 和模型
  - 管理手工资源引用
  - 在页内编辑相关资源记录
- 关键展示信息：
  - 当前阶段状态
  - 最近任务状态、进度和执行结果
  - 各阶段文本与摘要
  - 章节关联资源
- 与其他页面的关系：
  - 上游是书籍工作台。
  - 下游结果会影响阅读页是否可读。
  - 依赖资源中心中的结构化资料。

## 7. 资源中心

- 路由：`/app/books/:bookId/resources`
- 页面目标：维护这本书的结构化创作资料。
- 资源类型包括：
  - Outlines
  - World Settings
  - Characters
  - Factions
  - Relations
  - Items
  - Hooks
- 主要操作：
  - 切换资源类型标签
  - 列表浏览与排序
  - 创建资源记录
  - 编辑资源记录
  - 删除资源记录
- 关键展示信息：
  - 资源主字段
  - 资源状态
  - 更新与创建时间
  - 关联实体信息
- 与其他页面的关系：
  - 是章节工作台的重要上游数据源。
  - 与章节工作台共享资源编辑逻辑与实体选择逻辑。

## 8. 章节阅读页

- 路由：`/app/books/:bookId/read`
- 页面目标：只阅读最终成稿，而不混入草稿或中间态内容。
- 主要操作：
  - 切换章节
  - 上一章 / 下一章
  - 调整字号
  - 切换常规宽度 / 加宽版心
  - 切换亮色 / 暗色模式
- 关键展示信息：
  - 章节标题
  - 章节摘要
  - Final 正文内容
  - 当前是否已有 final 成稿
- 与其他页面的关系：
  - 如果章节没有 final，会提示返回章节工作台继续处理。
  - 它是面向成稿消费的终点页。

## 9. 个人设置页

- 路由：`/app/settings`
- 页面目标：管理当前用户的默认运行配置。
- 主要操作：
  - 选择默认 Provider
  - 维护通用模型与 Low / Mid / High 模型
  - 维护默认 Max Tokens
  - 配置 OpenAI / Anthropic / Custom 的连接参数
  - 清空个人覆盖
- 关键展示信息：
  - 用户个人覆盖值
  - Server Default
  - Effective 生效值
  - Provider 可用能力
- 与其他页面的关系：
  - 它为书籍工作台和章节工作台提供默认的 workflow 参数来源。
  - 单次 workflow 中的临时覆盖不等于全局默认值变更。

## 10. 应用外壳与全局导航

虽然 `AppShell` 不是单独路由页面，但它决定了整个应用的导航体验。

主要导航入口包括：

- 书籍总览
- 写作工作台
- 资源中心
- 章节阅读
- 个人设置

其中：

- 当用户还没有进入某本书时，书籍相关导航会保持禁用或回退。
- 当用户进入一本书后，导航会自动切换到当前书籍上下文。
- 顶部区域还会显示当前用户和退出登录入口。

## 11. 404 页面

- 路由：兜底 `*`
- 页面目标：处理未知或错误路径。
- 典型用途：
  - 用户输入了不存在的路径
  - 外部链接失效
  - 路由未注册

## 12. 页面理解建议

如果你想快速理解整个前端，可以按下面顺序看页面：

1. 书籍总览：理解系统入口。
2. 书籍工作台：理解书籍与章节之间的关系。
3. 章节工作台：理解系统最核心的生产流程。
4. 资源中心：理解结构化资料如何支撑章节 workflow。
5. 阅读页：理解 final 成稿的消费边界。
6. 个人设置：理解 workflow 默认参数从哪里来。
